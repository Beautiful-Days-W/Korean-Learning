1. 복습 · 세 동사 Quick review · 들르다 · 듣다 · 들다

세 동사, 어떻게 다를까요?
들르다 = to stop by a place — 가게에 들러요. (으 탈락: 들르 + 어 → 들러)
듣다 = to listen / take a class — 음악을 들어요. (ㄷ 불규칙: 듣 → 들)
들다 = to lift·hold / like(마음에 들다) / age(나이가 들다) — 가방을 들어요. (ㄹ 받침)
활용 한눈에 보기 — 초록칸(-(으)려고)에서 셋이 다 달라요.
기본형뜻현재(해요체)과거-(으)려고 하다-기로 하다
들르다stop by들러요들렀어요들르려고 해요들르기로 했어요
듣다 (ㄷ)listen들어요들었어요들으려고 해요듣기로 했어요
들다 (ㄹ)lift·like·age들어요들었어요들려고 해요들기로 했어요
⚠️ 현재형 함정: 듣다 → 들어요, 들다 → 들어요 — 똑같아요! 무엇을(음악을? 가방을?) 보고 문맥으로 구별해요.
✅ 하지만 -(으)려고에서는 갈라져요: 들르다 → 들르려고 · 듣다 → 들으려고(ㄷ불규칙) · 들다 → 들려고.
‘들다’의 여러 뜻 — very common.
마음에 들어요 (I like it) · 나이가 들어요 (getting older) · 돈이 많이 들어요 (costs a lot) · 잠이 들었어요 (fell asleep)

5. 🎬 실전 대화 — 여행 이야기 Talking about the trip

선생님과 번갈아 소리 내어 읽어요 (지호 ↔ 민수, 해요체). 그다음 대본을 덮고 내 여행 이야기로 바꿔 말해 봐요.

🙂 민수지호 씨, 이번 퀘벡 여행 준비 잘 돼 가요?
🧳 지호네, 가는 길에 몬트리올에도 들르려고 해요. 거기 구시가지가 예쁘다고 해서요.
🙂 민수좋네요! 운전하는 동안 심심하지 않아요?
🧳 지호아니요, 저는 운전하면서 팟캐스트를 자주 들어요. 여행 이야기 나오는 걸 들으면 시간이 금방 가요.
🙂 민수아, 저도 그래요. 숙소는 정했어요?
🧳 지호네, 구시가지 근처 호텔을 예약하기로 했어요. 사진을 보니까 정말 마음에 들었어요.
🙂 민수짐은 많이 챙겼어요?
🧳 지호아니요, 이번엔 가볍게 가려고 해요. 짐이 많으면 들고 다니기 힘드니까요.
🙂 민수현지에서 특별히 하고 싶은 거 있어요?
🧳 지호유명한 성당에서 하는 오르간 연주를 들으러 가기로 했어요. 소리가 정말 웅장하대요.
🙂 민수우와, 다녀와서 얘기 많이 들려주세요!
🧳 지호그럼요. 사진도 많이 찍어 올게요.

👩‍🏫 선생님 카드 말하기 중심 · 선생님은 짧게, 학습자가 길게

① 세 동사 속사포 (활용 자동화)

선생님이 "동사 + 형태"를 던지면 학습자가 바로 말해요. -(으)려고에서 갈라지는 걸 몸에 익히기.

  • 들르다 → 들르려고 해요 / 들르기로 했어요
  • 듣다 → 들으려고 해요(ㄷ!) / 듣기로 했어요
  • 들다 → 들려고 해요 / 들기로 했어요
  • 현재형 함정: "음악을 ___" → 들어요 / "가방을 ___" → 들어요 (같은 소리, 다른 뜻)

② 여행 이야기 인터뷰 (길게 말하기)

선생님이 짧게 물으면 학습자가 세 동사를 섞어 여행 이야기를 길게 해요.

  • "여행 가는 길에 어디 들르려고 해요?" → 도시·명소…
  • "이동할 때 뭘 들으려고 해요?" → 음악·팟캐스트·오디오 가이드
  • "숙소는 어디로 정하기로 했어요?" → 예약하기로/마음에 들다
  • "짐은 어떻게 하기로 했어요?" → 들다(가볍게/많이)

성공 기준: 들르다·듣다·들다를 -(으)려고 하다/-기로 하다로 정확히 구별해서, 주말 계획을 대본 없이 5문장 이상 말하기. (숙제 = 위 6번 쓰기 → 제출)
