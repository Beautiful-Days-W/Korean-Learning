0. 미니 복습 Quick review · L31–35

1. 원리 How it works (-(으)ㄹ 때)

① -(으)ㄹ 때 = "~할 때, 그 시간에" — "when ~ / while ~": the moment or period during which something happens.
동사·형용사 어간 + -(으)ㄹ 때. 받침 없음·ㄹ 받침 → -ㄹ 때, 받침 있음 → -을 때. ★ 때는 띄어 써요 (만들 때 ✓ · 만들때 ✗).
기본형규칙-(으)ㄹ 때예문
만들다ㄹ 받침 → -ㄹ 때만들 때송편을 만들 때 뜨거운 물을 써요.
찌다받침 없음 → -ㄹ 때찔 때송편을 찔 때 솔잎을 깔아요.
빚다 · 넣다 · 먹다받침 → -을 때빚을 때 · 넣을 때 · 먹을 때소를 넣을 때 조심해요.
듣다ㄷ 불규칙 → 들 + 을 때들을 때음악을 들을 때 행복해요.
덥다ㅂ 불규칙 → 더우 + ㄹ 때더울 때날씨가 더울 때 반죽이 빨리 말라요.
② -았/었을 때 = 이미 일어난 일 "~했을 때" — "when (something had happened / I was there)". Compare: 갈 때 = on the way there; 갔을 때 = when I was there (having gone).
한국에 갈 때 비행기에서 영화를 봤어요. (when going = on the way)
한국에 갔을 때 처음 토란국을 먹어 봤어요. (when I was in Korea)
송편이 다 익었을 때 찬물에 헹구고 참기름을 발라요. (once they're cooked)
처음 들었을 때 무슨 뜻인지 몰랐어요. (when I first heard it)
③ 명사 + 때 · 어릴 때 · 때마다 — with time nouns just add 때 (no -(으)ㄹ). 어리다 → 어릴 때 = "when I was little".
추석 때 온 가족이 모여요. · 명절 때는 한국 마트가 붐벼요. · 방학 때 한국에 갔어요.
✗ 추석일 때 → ✓ 추석 때 (time nouns: just 때)
어릴 때 할머니 옆에서 송편을 빚곤 했어요. (어리다 = to be young → 어릴 때)
명절 때마다 어머니가 갈비찜을 해 주셨어요. (때마다 = every time) · 송편을 먹을 때마다 할머니 생각이 나요.
④ -(으)ㄹ 때 vs -(으)면 vs -(으)면서 — "when (time)" vs "if/when (condition)" vs "while (doing two things at once)".
송편을 빚을 때 손에 물을 묻혀요. = 그 시간에 (when you shape them)
소를 너무 많이 넣으면 터져요. = 조건·결과 (if you put too much)
송편을 빚으면서 이야기를 해요. = 동시에 두 가지 (while shaping, at the same time)
⚠️ 때 앞은 항상 -(으)ㄹ(미래형 모양)이에요. 현재·과거 일이라도 -는 때·-던 때로 쓰지 않아요: ✗ 먹는 때 → ✓ 먹을 때. 지난 일은 -았/었을 때로!

5. 🎬 실전 대화 — 송편 같이 빚어요 Making songpyeon together

토요일, 민수가 지호 집에 와서 송편을 같이 빚어요. 선생님과 번갈아 소리 내어 읽어요 (지호 ↔ 민수, 해요체). 그다음 대본을 덮고 내가 잘 만드는 음식으로 바꿔 말해 봐요.

🙂 민수지호 씨, 저 왔어요. 우와, 반죽을 벌써 다 했네요?
🌕 지호네, 어머니가 아침에 하셨어요. 쌀가루를 반죽할 때 꼭 뜨거운 물을 써야 한대요. 그래야 안 갈라진대요.
🙂 민수아, 그렇군요. 저는 뭘 하면 돼요?
🌕 지호우선 손에 물을 조금 묻히세요. 반죽을 빚을 때 손에 안 붙어요. 반죽을 조금 떼어서 동그랗게 만들고, 가운데를 눌러서 소를 넣으면 돼요.
🙂 민수소는 뭐예요?
🌕 지호깨하고 설탕을 섞은 거예요. 소를 넣을 때 너무 많이 넣으면 찔 때 터져요. 그리고 반달 모양으로 꼭 눌러서 닫아요.
🙂 민수이렇게요? 제 건 좀 못생겼는데요.
🌕 지호하하, 괜찮아요. 저도 어릴 때는 제가 빚은 건 다 못생겼었어요. 한국에서는 송편을 예쁘게 빚으면 예쁜 아이를 낳는다는 말도 있어요.
🙂 민수그래요? 그럼 더 열심히 빚어야겠네요. 다 만들면 어떻게 해요?
🌕 지호찜기에 솔잎을 깔고 20분쯤 쪄요. 다 익었을 때 찬물에 살짝 헹구고 참기름을 발라요. 그러면 반짝반짝 예뻐요.
🙂 민수냄새가 벌써 좋을 것 같아요. 그런데 추석에 송편만 먹어요?
🌕 지호아니요. 토란국하고 갈비찜, 나물도 상에 올려요. 작년에 한국에 갔을 때 처음 토란국을 먹어 봤는데, 저한테는 좀 낯설더라고요.
🙂 민수저는 갈비찜이 제일 좋아요. 명절 때마다 어머니가 해 주셨어요.
🌕 지호그럼 오늘 저녁에 갈비찜도 같이 먹어요. 송편 다 찌고 나서 상을 차릴 때 좀 도와주세요.
🙂 민수네, 좋아요! 대신 설거지는 제가 할게요.

👩‍🏫 선생님 카드 말하기 중심 · 선생님은 짧게, 학습자가 길게

① 송편 빚기 설명하기 (길게 말하기)

위 6단계 그림을 보면서 학습자가 "~할 때는 …"으로 과정을 처음부터 끝까지 설명해요. 선생님은 "그다음에는요?" · "그때 뭘 조심해요?" · "왜요?"로만 밀어 주세요.

  • "먼저 뭐 해요?" → 반죽할 때는 뜨거운 물을 써요. 그래야 안 갈라져요.
  • "그다음에는요?" → 빚을 때는 손에 물을 묻혀요 · 소를 넣을 때는 너무 많이 안 넣어요.
  • "찔 때는요?" → 찔 때는 솔잎을 깔아요 · 다 익었을 때는 찬물에 헹구고 참기름을 발라요.
  • "다 만들었을 때 기분이 어땠어요?" → -았/었을 때로 대답 유도.
  • 대본을 덮고 내가 잘 만드는 음식으로 바꿔서 같은 흐름으로 (숙제 예행연습).

② -(으)ㄹ 때 ↔ -았/었을 때 속사포

같은 동사로 두 형태를 번갈아. 뜻 차이("가는 길에" vs "가 있을 때")를 짧게 확인.

  • 가다 → 한국에 갈 때 비행기에서 영화를 봤어요 ↔ 한국에 갔을 때 토란국을 먹어 봤어요
  • 먹다 → 송편을 먹을 때 차를 마셔요 ↔ 처음 먹었을 때 좀 낯설었어요
  • 듣다(ㄷ) → 음악을 들을 때 ↔ 처음 들었을 때 · 덥다(ㅂ) → 날씨가 더울 때 ↔ 작년 여름 더웠을 때
  • 명사 → 추석 때 · 명절 때마다 · 어릴 때 (✗ 추석일 때)

③ 추석 음식 인터뷰

  • "추석 때 뭘 먹어요?" → 송편·토란국·갈비찜·나물·전 … (L34 -기도 하고 -기도 해요로 이어 말하기)
  • "처음 먹었을 때 어땠어요?" → -았/었을 때 + -더라고요(L33) 결합: 처음 먹었을 때 좀 낯설더라고요
