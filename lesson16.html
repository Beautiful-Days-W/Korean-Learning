학습 목표 Goals

식당에서 예약하고, 주문하고, 요청하고, 계산하기 — 그리고 음식 맛 이야기까지. (Book, order, make requests, chat about the food, and pay.)

✓ 형용사 + -게 (해 주세요) = "make it ~ / do it ~ly": 덜 맵게 · 짜지 않게 · 따뜻하게 make it less spicy / not salty / warm
✓ 식당 회화: 몇 분·2인분·추천·빼 주세요·더 / 추가·따로 계산 party size · order · more(refill) vs add-on · split the bill

0. 미니 복습 Quick review

지난 과들에서 짧게. 답은 모두 해요체로 쓰세요 (기본동사는 [ ] 안에).

1. 원리 How it works (-게)

① 형용사 + -게 = "(do it) in a ~ way" — tell the staff HOW you want it.
맵다(spicy) → 맵게 · 따뜻하다(warm) → 따뜻하게 · 짜다(salty) → 짜게 · 빠르다(fast) → 빠르게
Just add -게 to the adjective — that's it, almost no exceptions.
Compare with L15's -(으)ㄴ 거 (which describes a thing): 큰 거 = "a big one" ↔ 크게 = "in a big way". Same 크-, different job.
「덜 맵게 해 주세요.」 = Please make it less spicy. · 「짜지 않게 해 주세요.」 = Not too salty, please.

② 더 vs 추가 — "more" vs "add".
「더 주세요」 = give me more of what's already served (side dishes, water, rice). · 「추가」 = add a new item/portion to the order (one more serving of bulgogi).
(In Korea, "더" of side dishes/water is usually free and "추가" is usually charged — but it varies by shop.)

③ 인분 vs 개수 — how to count food.
인분 = servings of a shared dish (meat, stew): 불고기 2인분. · A one-bowl dish is counted: 비빔밥 하나, 냉면 두 개.

④ 나눠 내기 (split the bill)
「따로 계산해 주세요」 · 「각자 계산할게요」 · 「나눠서 낼게요」 · 「더치페이 하자」(friends) = pay separately / each pays / split it.

⑤ 식당 회화 (handy phrases): 「몇 분이세요?」 = How many people? · 「추천해 주세요.」 = What do you recommend? · 「이건 빼 주세요.」 = leave this ingredient out (≠ 포장 = takeout/to-go).

6. 쓰기 숙제 Homework · write & submit

오늘 배운 표현으로, 식당에서 있었던(또는 있을) 일을 예약 → 주문(-게로 요청) → 식사 중 요청(더/추가) → 계산(따로)까지 이어서 3~5문장으로 써 보세요.

✅ -게 해 주세요, 더 / 추가, 따로 계산을 꼭 한 번씩 넣어요.

예: 저녁 일곱 시에 세 명 예약했어요. 비빔밥은 덜 맵게 해 달라고 했어요. 계란은 빼 달라고 했어요. 반찬을 좀 더 달라고 하고, 불고기 1인분을 추가했어요. 계산은 따로 했어요.

👩‍🏫 선생님 카드 말하기 드릴 · 선생님은 짧게, 학습자가 길게

① 대본 없이 롤플레이 (5번 대화 변형)

선생님=직원, 학습자=지호(손님). 대본을 덮고 다시 하되, 상황을 바꿔 던져 학습자가 즉흥으로 대응하게 하세요.

  • 예약: "죄송해요, 일곱 시는 만석이에요." → 학습자가 시간·인원 조정
  • 주문: "그 메뉴는 오늘 다 팔렸어요." → 다른 거 추천 부탁·주문 바꾸기
  • 요청: 음식이 너무 짜다·덜 익었다 → -게로 다시 부탁("덜 짜게 해 주세요")
  • 계산: "카드가 안 돼요." → 현금·따로 계산 등 대응

② -게 속사포 (형용사 → "-게 해 주세요")

선생님이 형용사를 빠르게 던지면 학습자가 -게로 즉답. "덜 / 더 / 안 ~게"까지 붙여 보게 하세요.

  • 맵다 → "덜 맵게 해 주세요."
  • 짜다 → "짜지 않게 해 주세요."
  • 달다 → "덜 달게 해 주세요."
  • 뜨겁다 → "너무 뜨겁지 않게 해 주세요."
  • 작다 → "더 크게 잘라 주세요."
  • 빠르다 → "빠르게 해 주세요." (= 빨리)
  • 바삭하다 → "바삭하게 튀겨 주세요."

더 던질 형용사: 싱겁다·많다·적다·부드럽다·차갑다·따뜻하다·질기다…

성공 기준: -게 · 더/추가 · 따로 계산을 멈칫 없이, 바뀐 상황 3개 이상을 대본 없이 대응. (숙제 = 위 6번 쓰기 → 제출)
