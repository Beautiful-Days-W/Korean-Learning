1. 원리 How it works (-(으)ㄴ/는 것 같다)

① -(으)ㄴ/는 것 같다 = "I think ~ / it seems ~" — a soft opinion or a guess.
형용사 (지금 상태) → -(으)ㄴ: 좋다 → 좋은 것 같아요 · 비싸다 → 비싼 것 같아요. (있다/없다 → -는: 재미있는 / 맛있는 것 같아요)
동사 (지금) → -는: 하다 → 하는 것 같아요 · 오다 → 오는 것 같아요
동사 (과거) → -(으)ㄴ: 가다 → 간 것 같아요 · 먹다 → 먹은 것 같아요
동사 (미래·추측) → -(으)ㄹ: 오다 → 올 것 같아요 (you learned this in L3!)

② 왜 쓰나 (why use it) — 단정을 피하고 부드럽게 말할 때.
「이게 더 좋아요.」 (단정) → 「이게 더 좋은 것 같아요.」 (I think this one's better.) — 훨씬 공손하고 자연스러워요.

③ 의견 회화 (handy phrases): 「제 생각에는 ~」 = in my opinion · 「동의해요」 = I agree · 「글쎄요」 = hmm, I'm not sure · 「맞아요 / 그런 것 같아요」

5. 🎬 실전 대화 — 주말 계획 의견 나누기 Sharing opinions about weekend plans

선생님과 번갈아 소리 내어 읽어요 (친구 A ↔ B, 해요체). 그다음 대본을 덮고 내 의견으로 바꿔 말해 봐요.

🙂 A이번 주말에 뭐 할까요? 영화 볼까요?
🙋 B좋아요. 그런데 요즘 볼 만한 영화가 별로 없는 것 같아요.
🙂 A그래요? 제 생각에는 이 영화가 재미있을 것 같아요. 요즘 인기가 많은 것 같아요.
🙋 B아, 그거 저는 봤는데 좀 지루한 것 같았어요. 이야기가 너무 긴 것 같아요.
🙂 A그렇군요. 그럼 다른 걸 할까요?
🙋 B공원에 가는 건 어때요? 요즘 날씨가 정말 좋아진 것 같아요.
🙂 A좋은 생각이에요. 그런데 오후에는 비가 올 것 같아요. 하늘이 좀 흐린 것 같아요.
🙋 B그럼 오전에 가는 게 좋겠어요. 오전에는 안 추운 것 같아요.
🙂 A동의해요. 그런데 공원에 사람이 많을까요?
🙋 B주말이라서 좀 많을 것 같아요. 그래도 산책하기에는 괜찮을 것 같아요.
🙂 A맞아요. 그럼 점심은 어디서 먹을까요?
🙋 B공원 앞에 새로 생긴 식당이 맛있는 것 같아요. 사람들이 줄을 서는 걸 봤어요.
🙂 A오, 그럼 거기로 가요. 그게 훨씬 좋은 것 같아요!
🙋 B좋아요. 그럼 토요일 오전에 만나요. 정말 기대돼요!

👩‍🏫 선생님 카드 말하기 중심 · 선생님은 짧게, 학습자가 길게

① 의견 주고받기 (부드럽게)

선생님이 화제를 던지면 학습자가 -(으)ㄴ/는 것 같다 + 제 생각에는으로 의견을 말해요. 단정형("좋아요")을 부드럽게("좋은 것 같아요") 바꾸는 연습!

  • "이 영화 어때요?" → "재미있는 것 같아요 / 좀 지루한 것 같아요"
  • "요즘 날씨 어때요?" → "많이 추워진 것 같아요"
  • "이 음식 맛있어요?" → "제 생각에는 좀 짠 것 같아요"
  • 선생님이 의견을 말하면 → "동의해요 / 글쎄요, 저는 ~ 것 같아요"

② 시제·품사 고르기 (헷갈리기 쉬움 — 많이 연습!)

선생님이 단어를 던지면 학습자가 -것 같아요로 즉답. 같은 동사로 지금(-는) / 과거(-(으)ㄴ) / 추측·미래(-(으)ㄹ)를 구분하는 게 핵심이에요.

▸ 동사 — 지금/과거/추측 3단 변형

  • 오다 → 지금 오는 / 아까 온 / 곧 올 것 같아요
  • 가다 → 가는 / 간 / 갈 것 같아요
  • 먹다 → 먹는 / 먹은 / 먹을 것 같아요
  • 하다 → 하는 / 한 / 할 것 같아요
  • 자다 → 자는 / 잔 / 잘 것 같아요
  • 읽다 → 읽는 / 읽은 / 읽을 것 같아요
  • 만들다(ㄹ) → 만드는 / 만든 / 만들 것 같아요
  • 듣다(ㄷ) → 듣는 / 들은 / 들을 것 같아요

▸ 형용사 — -(으)ㄴ (있다/없다·재미있다류는 -는)

  • 좋다 → 좋은 · 비싸다 → 비싼 · 크다 → 큰 · 예쁘다 → 예쁜 · 작다 → 작은 · 춥다(ㅂ) → 추운 것 같아요
  • 재미있다 → 재미있는 · 맛있다 → 맛있는 · 맛없다 → 맛없는 것 같아요 (있다/없다 → -는!)

▸ 명사 — 인 것 같아요

  • 학생 → 학생인 · 한국 사람 → 한국 사람인 · 지금 → 지금 세 시인 것 같아요

※ 함정: 형용사는 지금 상태라도 -(으)ㄴ(좋은 것 같아요), 동사 지금 진행은 -는(하는 것 같아요). 헷갈리면 "형용사=-(으)ㄴ, 동사 지금=-는"을 떠올려요.

성공 기준: -(으)ㄴ/는 것 같다로 단정을 피해 부드럽게 의견을 말하고, 동의·반대를 이어가기. (숙제 = 위 6번 쓰기 → 제출)
