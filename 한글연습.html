자음·모음 체계적으로 익히기 Learn the alphabet in order

읽기는 잘하지만 순서와 이름을 확실히 다지는 페이지예요. 자음·모음을 순서대로(ㄱㄴㄷㄹ… / ㅏㅑㅓㅕ…) 읽고 이름을 익힌 다음, 아래 연습에서 확인해요. (Solidify the order & names of the letters.)

1. 자음 Consonants (14) · 글자 · 이름 · 소리

글자를 보고 이름을 소리 내어 읽어요. (ㄱ = 기역)

➕ 쌍자음 (된소리): ㄲ(쌍기역) · ㄸ(쌍디귿) · ㅃ(쌍비읍) · ㅆ(쌍시옷) · ㅉ(쌍지읒)

2. 모음 Vowels (10) · 글자 · 소리

모음은 ㅇ과 함께 소리 내요. (ㅏ = 아)

➕ 복모음 (combined): ㅐ(애) · ㅔ(에) · ㅚ(외) · ㅟ(위) · ㅢ(의) · ㅘ(와) · ㅝ(워)

3. 가나다 표 Syllable chart · 소리 내어 읽기

자음(세로) + 모음(가로)을 합쳐 읽어요. 한 줄씩 소리 내어 읽어 보세요.

4. 쓰기 연습 ① — 자음 이름 Write the letter's name · 입력 즉시 채점

글자를 보고 이름을 쓰세요 (예: ㄱ → 기역).

5. 쓰기 연습 ② — 모음 소리 Write the vowel's sound

모음을 보고 소리를 글자로 쓰세요 (예: ㅏ → 아).

6. 순서 익히기 — 빈칸 채우기 Fill in the missing letter (order)

자음 순서(ㄱㄴㄷㄹ…)를 생각하며 빠진 글자를 쓰세요 (예: ㄱ ㄴ [ ] ㄹ → ㄷ).

7. 이름 보고 글자 쓰기 Name → letter

이름을 보고 자음을 쓰세요 (예: 기역 → ㄱ). 이름과 글자를 확실히 연결해요.
