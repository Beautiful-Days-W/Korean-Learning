0. 미니 복습 Quick review · L15–18

1. 원리 How it works (-(으)면서 · 빈도)

① 동사 + -(으)면서 = "while ~ing" — two actions at the same time, same person.
받침 없음 → -면서 (보다 → 보면서) · 받침 있음 → -으면서 (먹다 → 먹으면서) · ㄹ받침 → -면서 (만들다 → 만들면서)
ㄷ-irregular: 듣다 → 들으면서 · 걷다 → 걸으면서.
「음악을 들으면서 뛰어요.」 = I run while listening to music. · 「TV를 보면서 스트레칭해요.」

② 빈도 (how often)
「얼마나 자주 운동해요?」 = How often do you work out? · 「일주일에 세 번 해요.」 = Three times a week.
Pattern: 하루에 / 일주일에 / 한 달에 + number + 번. Frequency words: 매일(every day) > 자주(often) > 가끔(sometimes) > 거의 안(hardly).

③ 운동 회화 (handy phrases): 「운동한 지 얼마나 됐어요?」 = How long have you been working out? · 「살이 빠졌어요 / 쪘어요」 = lost / gained weight · 「숨이 차요」 = out of breath

5. 🎬 실전 대화 — 운동 습관 Talking about workout habits

선생님과 번갈아 소리 내어 읽어요 (해요체). 그다음 대본을 덮고 내 이야기로 바꿔 말해 봐요.

🙂 친구지호 씨, 요즘 운동해요?
🏃 지호네, 요즘 헬스장에 다녀요. 일주일에 세 번 가요.
🙂 친구우와, 자주 가네요. 주로 뭐 해요?
🏃 지호스트레칭하고 나서 러닝머신에서 뛰어요. 음악을 들으면서 뛰면 시간이 빨리 가요.
🙂 친구저는 뛰는 게 힘들어서 주로 걸어요.
🏃 지호걷기도 좋아요! 얼마나 자주 걸어요?
🙂 친구거의 매일 저녁에 공원에서 걸어요. 집에서는 TV 보면서 자전거도 타요.
🏃 지호운동한 지 얼마나 됐어요?
🙂 친구한 6개월 됐어요. 요즘 살도 좀 빠지고 몸이 가벼워졌어요.
🏃 지호좋네요. 저도 처음엔 숨이 찼는데, 이제 좀 괜찮아졌어요.
🙂 친구우리 다음에 같이 운동할까요?
🏃 지호좋아요! 같이 하면 더 재미있을 것 같아요.

6. 쓰기 숙제 Homework · write & submit

내 운동 습관을 3~5문장으로 써 보세요 — 무슨 운동을, 얼마나 자주, 뭘 하면서, 어떤 느낌인지.

예: 저는 일주일에 세 번 운동해요. 보통 음악을 들으면서 공원에서 걸어요. 운동하면 땀이 많이 나요. 운동한 지 6개월 됐는데, 요즘 몸이 가벼워졌어요.

👩‍🏫 선생님 카드 말하기 중심 · 선생님은 짧게, 학습자가 길게

① 운동 습관 인터뷰 (길게 말하기)

선생님이 짧게 묻고 학습자가 2문장 이상으로 답해요. 5번 대화를 내 이야기로 바꿔 말하게 하세요.

  • "무슨 운동 해요?" → 종류 + 장소
  • "얼마나 자주 해요?" → 일주일에 N번 / 매일 / 가끔
  • "운동할 때 뭐 하면서 해요?" → -(으)면서 (음악 들으면서 / TV 보면서)
  • "운동한 지 얼마나 됐어요?" → 기간 + 달라진 점
  • "운동하면 어때요?" → 땀이 나요 / 숨이 차요 / 몸이 가벼워요

② -(으)면서 속사포

선생님이 두 동작을 던지면 학습자가 -(으)면서로 즉시 연결.

  • 음악 듣다 + 뛰다 → "음악을 들으면서 뛰어요."
  • TV 보다 + 스트레칭하다 → "TV를 보면서 스트레칭해요."
  • 커피 마시다 + 이야기하다 → "커피를 마시면서 이야기해요."
  • 걷다 + 전화하다 → "걸으면서 전화해요."
  • 노래 부르다 + 청소하다 → "노래를 부르면서 청소해요."

성공 기준: -(으)면서 · 빈도(일주일에 N번/얼마나 자주)를 멈칫 없이, 내 운동 습관을 대본 없이 5문장 이상 이어 말하기. (숙제 = 위 6번 쓰기 → 제출)
